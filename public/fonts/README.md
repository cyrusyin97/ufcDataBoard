# Font notices

The bundled fonts use the Barlow and Barlow Condensed families.
Their copyright notice and SIL Open Font License 1.1 are included here.

- `font-0.ttf`: Barlow Regular.
- `font-1.ttf`: Barlow Medium.
- `font-2.ttf`: Barlow SemiBold.
- `font-3.ttf`: Barlow Bold.
- `font-4.ttf`: Barlow Condensed SemiBold.
- `font-5.ttf`: Barlow Condensed Bold.
- `font-6.ttf`: Barlow Condensed ExtraBold.

Read [the Barlow notice](OFL-Barlow.txt) and [the Barlow Condensed notice](OFL-BarlowCondensed.txt).
The notice sources are [Google Fonts Barlow](https://github.com/google/fonts/tree/main/ofl/barlow) and [Google Fonts Barlow Condensed](https://github.com/google/fonts/tree/main/ofl/barlowcondensed).
